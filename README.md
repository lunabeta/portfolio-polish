# 🌟 Vite React Portfolio Project 🌟
🔍 This project is a personal portfolio website built using Vite, React, and TypeScript. It features a modern and responsive design, with a focus on showcasing skills, experience, and projects. The project utilizes various libraries and tools, including React Router, Radix UI, and Tailwind CSS, to provide a seamless and interactive user experience.

## 🚀 Features
- **Responsive Design**: The website is fully responsive and adaptable to different screen sizes and devices.
- **React Router**: The project uses React Router for client-side routing, allowing for smooth navigation between pages.
- **Radix UI**: Radix UI components are used to provide a consistent and accessible UI.
- **Tailwind CSS**: Tailwind CSS is used for styling and layout, providing a flexible and customizable design system.
- **TypeScript**: The project is built using TypeScript, ensuring type safety and maintainability.
- **Vite**: Vite is used as the development server and build tool, providing fast and efficient development and production builds.

## 🛠️ Tech Stack
* Frontend: React, React Router, Radix UI, Tailwind CSS
* Backend: None (static site)
* Build Tool: Vite
* Language: TypeScript
* Dependencies: `react`, `react-dom`, `react-router-dom`, `@radix-ui/react-accordion`, `@radix-ui/react-alert-dialog`, `clsx`, `date-fns`, `framer-motion`
* DevDependencies: `@eslint/js`, `@types/react`, `@types/react-dom`, `typescript`

## 📦 Installation
To get started with the project, follow these steps:
1. Clone the repository using `git clone https://github.com/your-username/your-repo-name.git`
2. Install the dependencies using `npm install` or `yarn install`
3. Start the development server using `npm run dev` or `yarn dev`

## 💻 Usage
To run the project, use the following commands:
* `npm run dev` or `yarn dev` to start the development server
* `npm run build` or `yarn build` to build the project for production
* `npm run preview` or `yarn preview` to preview the built project
